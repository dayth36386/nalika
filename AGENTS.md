## Commit messages

Releases are automated with semantic-release (see README → Versioning), so every commit message must use a Conventional Commits prefix: `feat:` (new feature → minor), `fix:` / `perf:` (→ patch), `feat!:` (→ major), or `docs:` / `chore:` / `style:` / `refactor:` / `ci:` (no release).
